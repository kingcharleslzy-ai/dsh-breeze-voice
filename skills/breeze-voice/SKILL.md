# Breeze 语音聊天管理

使用专用工具，不要编辑配置文件、运行 shell 或要求重启 DSH。保留用户未提及的设置。技能本身不启动麦克风或创建会话。

## 配置与角色

1. 调用 `breeze_voice_settings`，`action: get`，读取当前值和 revision。
2. 用户明确要求修改时，用 `action: update` 携带该 revision 和仅包含所需字段的 patch。原生侧栏和工具使用同一份持久配置；作用范围是当前 DSH profile 的语音会话。普通聊天中临时指定说话风格，不代表要求修改持久设置。
3. 冲突时重新读取，核对用户所需字段后重试，不覆盖他人刚改的其他字段。
4. 按返回的 saved、server_sync、effect 报告。服务器离线时可能本机已保存但远端未同步，此时说清状态，使用 `breeze_voice_service` 的 `sync_idle` 重试；不能声称显存释放策略已生效。

例：
- “闲置五分钟释放显存” → patch `{idleMinutes:5}`。0 表示不自动卸载，范围 0–120 整数分钟。
- “等我停两秒再发送，允许打断” → `{silenceMs:2000,bargeIn:true}`。范围 400–3000 毫秒。
- “识别结果先让我确认” → `{reviewBeforeSend:true}`。
- “把星河语音加进识别热词” → 读取已有 asrHotwords，保留旧热词再追加；最多 2000 字。
- “保存耐心英语老师角色” → `{personaName:"英语老师",personaPrompt:"…",personaEnabled:true}`，最多 80/6000 字。目前保存一个当前角色，不宣称具有多角色预设库。
- “修改语音模式的默认提示词” → voicePrompt / voicePromptEnabled。角色和默认提示词只注入语音连接中的会话，下一次模型请求生效，不修改普通文字聊天的人设。

silenceMs、bargeIn、reviewBeforeSend 在下次开始语音通话生效。切换 asrEngine 前必须结束当前通话；server 为远端中文识别，dsh 为已准备好的 DSH 原生识别。原生模型未就绪时工具拒绝切换，不自动下载或改用其他提供方。asrHotwords 在下一次识别请求生效（原生识别不保证支持热词）。

## 固定音色

先用 `breeze_voice_voices` 的 list 获取真实名称、描述、ID、当前选择和 revision。明确名称或风格匹配唯一时 select；多个候选无法判断时询问偏好。禁止编造 ID。

已有适合声音就 select。用户要求设计新声音时 create，提供名称和声音描述；创建会在服务器生成并保存一段参考音频，让后续语句复用同一声音。创建不自动选择，用户同时要求使用它时再 list/select。超时或取消后先 list 检查，不重复创建。不支持删除、改名、录音克隆或独立语速参数，不宣称支持。

instruction 只是新音色描述草稿，改它不会改变已经固定的声音。不要为每句话重新设计音色。切换固定声音对下一段新合成生效，正在播放或已排队的音频保持原样。

## 服务与报告

`breeze_voice_service` 的 status 查询服务；release 仅在用户要求释放语音模型且无通话时调用，忙碌会拒绝。不停止 SSH 以外的服务，不关闭 Qwen 或视频模型，不修改密钥、端口、代理、服务器部署。

保存成功后简短说明改了什么、作用范围、何时生效。只有经过工具确认的结果才算完成；不能把描述草稿保存、模型配置保存或超时误报为声音已切换、GPU 已释放或音色创建成功。
